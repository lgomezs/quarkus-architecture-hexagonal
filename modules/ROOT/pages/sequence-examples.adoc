== Diagramas de Secuencia

Ejemplo de diagrama de secuencia en Mermaid:

[source,mermaid]
----
sequenceDiagram
  actor Cliente
  Cliente->>API: Solicita recurso
  API->>Servicio: Procesa solicitud
  Servicio->>DB: Consulta
  DB-->>Servicio: Resultado
  Servicio-->>API: Respuesta
  API-->>Cliente: Entrega respuesta
----
